# 🪔 Diwali Sales Data Analysis using Python
## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on Diwali sales transaction data to understand customer purchasing behavior, identify sales patterns, and generate meaningful business insights.
The analysis was performed using Python-based data analytics techniques to clean, process, visualize, and interpret customer and sales data. The objective of this project is to transform raw sales records into actionable insights that can help businesses improve customer targeting, marketing strategies, and sales planning.
## 🎯 Project Objectives
The main objectives of this project are:
  - Perform data cleaning and preprocessing
  - Analyze customer demographics and purchasing patterns
  - Identify top-performing product categories
  - Understand state-wise sales contribution
  - Analyze customer segments based on different attributes
  - Visualize sales trends and extract business insights
# 🛠️ Technologies Used
## Programming Language

  - Pandas – Data manipulation and analysis
  - NumPy – Numerical computations

## 📂 Dataset Information
The dataset contains Diwali sales transaction records with customer-related and purchase-related information.
Dataset Features Include:
  - User ID
  - Customer demographics
  - Gender
  - Age Group
  - Marital Status
  - State
  - Zone
  - Occupation
  - Product Category
  - Product ID
  - Orders
  - Amount
## Dataset Size:
  - 11,251 customer transactions
  - Multiple customer and sales attributes
# 🔍 Analysis Performed
## 1. Data Cleaning
Performed:
  - Missing value detection and handling
  - Removal of unnecessary columns
  - Data type correction
  - Data consistency checks
## 2. Customer Demographic Analysis
Analyzed customer purchasing behavior based on:
  - Gender
  - Age groups
  - Marital status
  - Occupation
## 3. Sales Analysis
Explored:
  - Total orders
  - Revenue contribution
  - Product category performance
  - State-wise sales distribution
## 4. Data Visualization
Created visualizations using:
  - Bar charts
  - Count plots
  - Distribution plots
  - Category-wise comparisons
### Visualization helped identify patterns and trends hidden inside the raw dataset.
# 📊 Key Insights
## Some important findings from the analysis:
  - Female customers showed higher purchase contribution compared to male customers.
  - The 26–35 years age group represented the most active customer segment.
  - Major product categories contributed significantly to overall revenue generation.
  - Certain states showed higher customer participation and sales contribution.
  - Customer demographic analysis provided insights for targeted marketing strategies.
## 💡 Business Recommendations
Based on the analysis:
  - Focus marketing campaigns on high-performing customer segments.
  - Improve personalized recommendations based on customer behavior.
  - Optimize inventory planning for high-demand categories.
  - Use demographic insights for targeted promotional campaigns.
